## 1. weight 字段的本质

### 问题

weight 字段（0-1）应该反映什么？

### 决策

**weight 反映"实际匹配程度"，而非"证据链可信度"**。

### 思考过程

1. **第一性原理分析**：
   - weight 的最终目的是帮助 LLM 筛选出最匹配的原型
   - 匹配程度应该基于实际效果（吸附容量、选择性等）
   - 证据链可信度是"置信度"，不是"匹配程度"

2. **两个概念的区分**：
   - **weight（匹配程度）**：原型对污染物的实际匹配程度 → 用于排序、筛选
   - **confidence（置信度）**：文献证据的可信度 → 用于评估结果的可靠性

3. **例子**：
   - chitosan 对 Hg²⁺：文献很多（证据链强），但吸附容量一般（匹配程度中等）
   - sulfate-reducing-bacteria 对 Hg²⁺：文献较少（证据链弱），但吸附容量极高（匹配程度高）

### 结论

weight 应该反映实际匹配程度，而不是证据链可信度。

## 2. LLM 赋分的权重分配

### 问题

LLM 赋分时，应该以什么为主？

### 决策

**以推理和知识为主（70%），文献数据为辅（20%），证据链为参考（10%）**。

### 思考过程

1. **推理和知识**（主要依据）：
   - 材料科学原理（配位化学、静电作用、π-π堆积等）
   - 吸附理论（吸附容量、选择性、动力学等）
   - 已知的材料-污染物匹配规律

2. **文献数据**（辅助验证）：
   - 吸附容量数据（验证 LLM 推理）
   - 选择性数据（补充 LLM 知识）
   - 机理描述（确认 LLM 判断）

3. **证据链**（参考置信度）：
   - 文献数量、质量等
   - 用于评估结果的可靠性

### 结论

LLM 赋分时，应该以推理和知识为主，文献数据为辅，证据链为参考。

## 3. 匹配机制设计

### 问题

如何从候选池中筛选出最匹配的原型？

### 决策

**排序为主 + 阈值兜底**：按 weight 排序，取 top 5，weight ≥ 0.5 作为兜底。

### 思考过程

1. **筛选方式**：
   - 固定阈值：weight ≥ 0.7（简单直接，但可能遗漏好原型）
   - 动态阈值：取 top N（更灵活，但可能包含低质量原型）
   - 双阈值：同时满足分数和排名（最科学）

2. **候选池大小**：
   - 10 个太多（信息过载）
   - 3-5 个合适（足够多样，不会过载）

3. **兜底阈值**：
   - 0.5 作为兜底，排除明显不相关的
   - 通常不会干扰推荐名单，只是最后的保障

### 结论

采用动态阈值（top 5）+ 兜底阈值（0.5）的组合方式。

## 4. weight 赋值方法

### 问题

如何根据文献赋 weight 值？

### 决策

**提参时同步赋值**：LLM 提取原型信息时，同时输出 weight 值。

### 思考过程

1. **方案对比**：
   - 方案 A：提参时同步赋值（一步到位，效率高）
   - 方案 B：提参后独立赋值（分两步，职责清晰）
   - 方案 C：先不赋 weight，后续补充（先完成基础建设）

2. **方案选择**：
   - 方案 A 更符合实际工作流程
   - 赋值依据更直接（原始文献）
   - 可以自动化（LLM 提参时输出 weight）

3. **赋分依据**：
   - 吸附容量（主要）：文献报道的吸附容量数据
   - 选择性（次要）：对目标污染物的选择性
   - 机理清晰度（辅助）：吸附机理的明确程度

### 结论

采用方案 A：提参时同步赋值。

## 5. 匹配流程设计

### 问题

完整的匹配流程是什么？

### 决策

**三层匹配 + 兜底阈值**：条件预筛 → weight 排序取 top 5 → 兜底阈值 0.5 → 组合推理。

### 流程图

```
输入：污染物 + 水质条件（pH、温度、盐度等）
    ↓
Layer 1 条件预筛：排除不适用的原型（基于 applicability）
    ↓
Layer 2 污染物匹配：按 weight 排序，取 top 5
    ↓
兜底阈值：weight ≥ 0.5（排除明显不相关的）
    ↓
输出：候选池（3-5 个原型）
    ↓
Layer 3 组合推理：LLM 读取候选池详情，提出组合方案
```

### 设计原则

- **排序为主**：按 weight 排序，取 top N
- **阈值兜底**：weight ≥ 0.5 作为兜底保障
- **动态调整**：weight 作为参考值，LLM 可根据具体情况调整

## 6. 关键设计决策总结

| 决策 | 选择 | 理由 |
|------|------|------|
| **weight 本质** | 实际匹配程度 | 帮助 LLM 筛选最匹配的原型 |
| **赋分主体** | LLM 动态赋分 | 以推理和知识为主，文献数据为辅 |
| **匹配机制** | 排序为主 + 阈值兜底 | top 5 + weight ≥ 0.5 |
| **赋值方法** | 提参时同步赋值 | 一步到位，效率高 |
| **匹配流程** | 三层匹配 + 兜底阈值 | 条件预筛 → 排序 → 组合推理 |
